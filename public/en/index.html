AI agent evaluation

QA Agent

Testing an AI agent used to take hours. Now it takes minutes.

How it works

  • One agent builds a battery of test scenarios from the business context.
  • Another talks to the agent under test the way a real customer would.
  • A judge agent reviews every conversation, scores it from 0 to 100 and points out error patterns.

Stack

  • Multi-agent orchestration
  • LLM-as-a-judge
  • LangChain
  • JavaScript

Sales Ops on WhatsApp

X9 Agent

No client forgotten across dozens of WhatsApp groups.

How it works

  • Monitors client groups Monday to Friday and spots conversations with no real reply.
  • Runs two checks a day and flags who on the team hasn't answered.
  • Logs everything to a database and sends a weekly performance report, recognizing whoever hit 100%.

Stack

  • n8n
  • Event-driven integration
  • WhatsApp
  • Database

AI for marketing

VSL Optimizer

Sales video briefs reviewed and rewritten in minutes, not days.

How it works

  • Six chained LLMs, each specialized in a copywriting framework, analyze the brief.
  • Each block gets a score from 0 to 10: opening, story and offer.
  • The system points out weak spots and delivers a new version ready to record.

Stack

  • LLM pipeline
  • Prompt chaining
  • n8n
  • Lovable
