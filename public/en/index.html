Systems built

Real problems, solved with AI.

Three documented systems, from problem to solution.

01Sales Ops · WhatsApp

X9 Agent

Customer service supervisor for WhatsApp

Problem

Managers can't tell whether clients in dozens of WhatsApp groups are being served or ignored.

Solution
  • Monitors the groups Monday to Friday and checks that real service happened.
  • Runs twice a day (5 pm and 6 pm) and flags who hasn't moved.
  • Congratulates managers with 100% service coverage (gamification).
  • Logs everything to a database and sends a weekly report.

V1 working · V2 in development

  • n8n
  • Event-driven integration
  • WhatsApp
  • Database
02LLM evaluation

QA Agent

A meta-agent that tests other agents

Problem

Every prompt change needs a manual testing cycle to make sure nothing broke.

Solution
  • A generator agent creates a battery of test scenarios.
  • A simulator agent talks to the agent under test like a real customer.
  • A judge agent reviews everything, scores it from 0 to 100 and flags error patterns.

Completed

  • Multi-agent orchestration
  • LLM-as-a-judge
  • LangChain
  • JavaScript
03AI for marketing

VSL Optimizer

AI analysis of sales briefs

Problem

VSL (video sales letter) briefs are hard to evaluate and often lead to underperforming campaigns.

Solution
  • A pipeline of 6 specialized LLMs, each following a copywriting framework.
  • A 0 to 10 score for each block: lead, story and offer.
  • A diagnosis of weak points and a new, ready-to-use version of the brief.

Completed

  • LLM pipeline
  • Prompt chaining
  • n8n
  • Lovable front end

How it works

From problem to a running system.

  1. 01

    Understand the problem

    Before any tool, the current process is mapped: where there is rework, delay or a lack of visibility.

  2. 02

    Design the solution

    Flow, data and integrations are designed end to end, with clear rules and points for human review.

  3. 03

    Build, measure, evolve

    The system goes live with metrics and reports. Based on the numbers, it evolves in versions.
